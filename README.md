This project is developed as part of the Wipro Capstone Assignment 2. The objective of this assignment is to design and implement a 
robust Selenium Python automation framework for an e-commerce application.
The framework automates key functionalities such as user login and product searc* while demonstrating industry-relevant automation 
practices including **Page Object Model (POM), PyTest, Unittest, Data-Driven Testing, configuration management, reusable utilities, 
cross-browser testing, logging, screenshots, and HTML reporting.
Through this project, I have focused on building an automation framework that is structured, reusable, maintainable, and easy to 
extend for additional test scenarios.
